# Frontend Project

## Описание

Веб-приложение для управления платежами и контактами, разработанное с использованием React и TypeScript. Проект следует архитектуре Feature-Sliced Design (FSD) для обеспечения масштабируемости и поддерживаемости кода.

## Функциональность

-   Управление платежами
-   Контактная информация
-   Информация о компании
-   Главная страница с основной информацией

## Технологический стек

-   React 18
-   TypeScript
-   React Router v6
-   Vite
-   CSS Modules

## Структура проекта

```
src/
├── app/         # Глобальные компоненты приложения
│   └── layouts/ # Макеты приложения
├── pages/       # Страницы приложения
│   ├── Home/    # Главная страница
│   ├── about/   # Страница "О нас"
│   ├── contacts/# Страница контактов
│   └── payment/ # Страница оплаты
├── widgets/     # Самодостаточные блоки для страниц
├── features/    # Функциональности, бизнес-логика
├── shared/      # Переиспользуемые модули
└── types/       # TypeScript типы и интерфейсы
```

## Реализованные страницы

1. **Главная страница** (`/`)

    - Основная информация о проекте
    - Навигация по разделам

2. **Страница "О нас"** (`/about`)

    - Информация о компании
    - История и миссия

3. **Страница контактов** (`/contacts`)

    - Контактная информация
    - Формы обратной связи

4. **Страница оплаты** (`/payment`)
    - Система управления платежами
    - Информация о транзакциях

## Установка и запуск

### Предварительные требования

-   Node.js (версия 14 или выше)
-   npm (версия 6 или выше)

### Установка зависимостей

```bash
npm install
```

### Запуск в режиме разработки

```bash
npm run dev
```

### Сборка проекта

```bash
npm run build
```

## Архитектура

### Основные компоненты

1. **App.tsx**

    - Центральный компонент приложения
    - Настройка маршрутизации
    - Интеграция общего макета

2. **AppLayout**

    - Общий макет для всех страниц
    - Навигационное меню
    - Футер

3. **main.tsx**
    - Точка входа приложения
    - Инициализация React
    - Подключение глобальных стилей

## Особенности реализации

-   Модульная архитектура
